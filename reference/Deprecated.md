# Deprecated functions

Deprecated performance metric functions. These functions are now
replaced with functions of same name but prefixed with `P_`.

## Usage

``` r
PNI50(...)

PNI80(...)

WILD50(...)

SMSY85(...)

Sgen100(...)
```

## Arguments

- ...:

  Same arguments as
  [`P_PNI50()`](https://docs.salmonmse.com/reference/P_PNI50.md) and
  similar functions

## Value

A vector of probabilities
